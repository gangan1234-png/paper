# Multimodal Semantic Diagnosis and Controllable Visual Repair Framework

This repository contains the core code and de-identified datasets for our study on historical urban streetspace restoration (e.g., Changsha case study).

## Environment Requirements
- Python 3.9+
- PyTorch 2.0+
- torchvision, transformers, sentence-transformers

## Quick Start
1. Clone the repo:
   `git clone https://github.com/你的用户名/你的仓库名.git`
2. Install dependencies:
   `pip install -r requirements.txt`
3. Run the main inference script:
   `python visual_repair_inference.py`
